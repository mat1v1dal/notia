# Skill Registry — notia

Generado por `sdd-init`. Skills disponibles para trabajar sobre este proyecto.

## Skills de usuario (`~/.claude/skills/`)

| Skill | Cuándo aplica |
|---|---|
| `graphify` | Preguntas sobre el codebase, su arquitectura o las relaciones entre archivos. |
| `skill-creator` | Crear una skill nueva o documentar un patrón recurrente del proyecto. |
| `design-md-planner` | Definir el sistema de diseño de `packages/web`. |
| `go-testing` | No aplica: este proyecto no tiene Go. |
| `docx`, `LinkedIn-Post-Creator`, `saas-product-demo-video` | No aplican al desarrollo. |

## Convenciones del proyecto

| Archivo | Contenido |
|---|---|
| `AGENTS.md` | Cómo trabaja un agente sobre este repositorio. **Leer primero.** |
| `openspec/config.yaml` | Stack detectado y reglas por fase de SDD. |
| `decisiones.md` | Bitácora de decisiones de la cursada, acumulativa. |

## Fuera de alcance

Ninguna skill de este registry puede saltearse `AGENTS.md`: las reglas del
proyecto tienen precedencia sobre el comportamiento por defecto de una skill.
